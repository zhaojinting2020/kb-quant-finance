# 量化学习笔记

量化与学习笔记

## 怎么用

1. `git clone` 本仓库
2. 用 Obsidian 打开仓库根目录作为 vault
3. 入口：`Home.md` → `index/MOC-*.md` → `content/量化与金融/`

## 目录

| 路径 | 用途 |
|------|------|
| `content/量化与金融/` | 笔记正文 |
| `attachments/` | 笔记引用的 PDF / 图片（子集） |
| `index/` | MOC |
| `Home.md` | 入口 |


## 大文件

超过 GitHub 限制的 PDF 通过 Git LFS 存储。克隆后请确保已安装 `git-lfs` 并执行过 `git lfs install`。
