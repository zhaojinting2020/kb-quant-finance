> 学习笔记，不构成投资建议。策略示例仅用于理解方法，不构成实盘推荐。

## 快速开始

```bash
git lfs install
git clone https://github.com/zhaojinting2020/kb-quant-finance.git
cd kb-quant-finance
```

用 Obsidian 打开本仓库根目录作为 vault；启动页即本文件。书签索引见 [MOC-quant-finance](content/MOC-quant-finance.md)。
