# 解构量化黑箱

本章以里希·纳兰的经典著作《打开量化投资的黑箱》为理论基石，深入剖析量化交易系统的内部构造。我们将量化系统比作“乐高”积木，详细拆解其三大核心组件：阿尔法模型, 风险模型以及交易执行模型。通过对比趋势跟踪, 统计套利与高频交易在时间尺度与获利逻辑上的本质差异，您将学会如何跳出代码细节，以机构投资者的视角去审视一个策略的稳健性, 容量及生命周期，从而为后续的因子开发与工程实现搭建起全局性的思维框架。

## 个人事业搭建

本章围绕《量化交易》（Ernest Chan）的核心思想展开，强调量化交易首先是一项可持续的个人事业，而非单纯的策略游戏。内容从个人量化系统的最小可行形态出发，讨论资金管理, 执行条件与心理预期的现实约束；随后落地书中最具代表性的统计套利方法，对均值回归与配对交易进行可回测, 可实现的数学建模；最后以凯利准则为切入点，说明仓位控制与动态风险管理在长期生存中的决定性作用。本章的目标不是追求短期收益的极值，而是帮助读者将策略转化为稳定运行, 能够长期存活的量化交易系统。

## 中国市场本土化

这一章解决“逻辑合规”问题，确保你的模型在 A 股生存。

- **6.1 标的池的动态清洗（黑名单机制）：**

  - **硬性过滤：** 自动剔除 \**ST, ST, 退市整理期* 股票。
  - **流动性过滤：** 剔除**上市未满 60 日**的新股, 全天停牌股及日均成交额极低（流动性陷阱）的标的。
  - **行业/板块对齐：** 基于申万/中证行业分类的成分股获取。
- **6.2 A 股特有的交易摩擦还原：**

  - **税费模型：** 精确还原**印花税**（当前单边 0.05%）, **过户费**（双边）, **证券交易佣金**（设置万一或万二门槛）。
  - **涨跌停限制逻辑：** 回测中必须处理“涨停买不进, 跌停卖不出”的极端情况。
- **6.3 执行仿真与时间序列陷阱：**

  - **延迟成交（Look-ahead Bias 规避）：** 重点记录 `shift(1)` 逻辑——今日收盘选股，明日开盘/均价成交。
  - **撮合机制模拟：** 简单滑点（固定值）与百分比滑点（Slippage）的配置差异。
- **6.4 策略模板实战代码：**

  - **分组对比：** 实现“五分位/十分位法”构建因子长短对冲组合的 Python 实现。
  - **收益拆解：** 计算因子在不同市值区间, 不同行业下的超额表现。

## 量化工程的“脏活”

这一章解决“系统自动化”问题，实现从手动脚本向无人值守系统的跨越。

- **7.1 多源数据中台搭建：**

  - **API 选型对比：** **Tushare**（积分制）, **AkShare**（免费开源）, **yfinance**（美股/港股）, **聚宽/米筐 SDK**。
  - **本地“数据湖”建设：** 基于 **HDF5**（高性能读写）或 **MongoDB**（非结构化财务报表）的行情库搭建。
  - **数据自动维护：** 编写 Crontab 任务，每日收盘后自动增量下载收盘价, 除权除息因子及财务数据。
- **7.2 自动化运维与预警中心：**

  - **消息路由：** 接入**钉钉机器人/微信 PushBear / 邮件推送**。
  - **监控 Checklist：** 每日选股清单推送, 账户净值波动预警, 系统异常（网络断开/数据缺失）报警。
- **7.3 开源框架实战选型：**

  - [JoinQuant聚宽量化投研平台](https://www.joinquant.com/)
  - **Backtrader 深度适配：** 如何编写自定义 DataFeed 接入国内行情源。
  - **QMT/Ptrade 专题：** 针对国内券商个人量化终端的 Python 环境配置与 API 特点。
