# 财务报表分析与基础

## 财务报表基础
### 基本概念
会计和财务管理的关系
- 会计是记账，算账，报账的人，是和信息有关的人
- 财务管理是投资，筹资，成果分配的人，是和资金有关的人

财务报表分析
- 在企业筹资的过程中，我们投资人审核的内容，是会计信息和财务信息。而这些信息的载体就是报表。
- 财务管理的结果反映在会计信息上，而会计信息支持企业进行财务管理。会计报表和财务报表
- 财务报表：反映企业财务状况的报表。能够用货币表现的状况叫财务状况。分别为资产负债表，利润表，现金流量表和股东权益变动表。
- 会计报表：企业的会计机构部门人员提供的报表。分别为分别为资产负债表，利润表，现金流量表，股东权益变动表和内部管理性的报表。
- 但是一般不对这两者进行区分，可以认为两者是同一个东西。资产和负债
- 资产：能够用货币表现的资源。不宜用货币表现的其他资源包括：
- 人力资源美国会计已经将人力资源列入“无形资产”，而在我国仍未列入“无形资产”。人力资源并非一直属于特定企业，人才资源的取得难以衡量。
- 组织文化
- 品牌形象
- 上下游关系的商业网络
- 股东资源
- 负债（股东权益）：资产来源

**对资产的分类**
- 流动资产：一年内可以转化为货币的资产，如家电类企业的存货。或者一个经营周期内，能转换成货币的资产，如房地产企业的存货。
- 货币资金
- 债权
- 存货
- 非流动资产：一年以上或者一个经营周期以上，能转换成货币的资产
- 投资
- 固定资产类
- 无形资产类

按照对利润的贡献方式/扩张方式分类
- 经营资产：企业在日常经营活动中投入并使用的资产，用于生产, 销售商品或提供劳务，从而直接产生营业收入和利润。
- 货币资金
- 债权
- 存货
- 固定资产类
- 无形资产类
- 投资资产：企业以获取投资收益或资本增值为目的持有的资产，不直接参与企业主营业务，但能通过投资收益, 股利, 利息或资产升值对利润做出贡献。
- 投资

资产负债表的负债部分代表了企业的权益归属 -- 企业发展的动力机制传统的权益分类只关注负债率而没有关注债务结构。
**对负债的分类**
- 流动负债（Current Liabilities）：企业在一年内或超过一年的一个营业周期内需要偿还的债务。如应付账款, 短期借款, 应付职工薪酬, 应交税费, 一年内到期的长期借款。
- 非流动负债（Non-current Liabilities）：企业在超过一年或超过一个营业周期后才需偿还的债务。如长期借款, 应付债券, 长期应付款, 长期租赁负债。
- 经营性负债（Operating Liabilities）：是指企业在日常经营活动中自然形成的, 不需要支付利息的负债。
- 应付票据
- 应付账款
- 预售款项
- 应付职工薪酬
- 应交税费
- 金融性负债（Financing Liabilities）：是企业为了筹集资金而产生的，需要付息或偿还本息的负债。
- 短期借款
- 一年内到期的非流动负债
- 应付短期债券
- 长期借款
- 应付债券

**对股东权益的分类**
- 股东入资
- 实收资本
- 资本公积
- 利润积累
- 盈余公积
- 未分配利润

总的来说，企业发展的四大动力因素分别为：经营性负债，金融性负债，股东入资和利润积累。资产是企业发展的 **基础和载体**；融资与利润才是企业发展的 **动力**。

**对现金流量的分类**

经营活动产生的现金流量，主要包括：
- 销售商品，提供劳务收到的现金
- 购买商品，接受劳务支付的现金
- 支付给职工，以及为职工支付的现金
- 支付的各项税费

投资活动产生的现金流量，主要包括：
- 构建固定资产，无形资产和其他长期资产支付的现金
- 处置固定资产，无形资产和其他长期资产收回的现金净额
- 投资支付的现金
- 收回投资收到的现金
- 取得投资收益收到的现金

筹资活动产生的现金流量，主要包括：
- 发行股票
- 分配股利
- 取得借款收到的现金
- 偿还债务支付的现金

现金流量表是企业一定时期货币资金分类收支汇总表。

## 财务报表信息分析
### 企业战略与财务分析的关系
如果把企业的资产按照经营资产和投资资产进行区分，可以把企业分成三类：
- 经营主导型
- 投资主导型
- 经营与投资并重型

经营主要型企业的特点：
- 地域集中度高
- 业务连续度紧密 -- 专业化程度高

- 其他应收款：
  - 母公司24.18亿。巨额其他应收款可能是向其他关联方提供的资金。一般从经验来看，其他应收款在总资产的规模不超过1%。

- 13亿差额是子公司欠的。

- 总资产：母公司549亿。合并报表1022亿。差额约600亿。通过160亿的对外控制性投资，撬动了600亿的增量。一般从经验来看，对外控制性投资与撬动的增量达到1：1以上，就是比较不错的撬动效应了。美的集团是一个投资主导型公司。通过对外控制性投资实现了其多元化战略。

### 企业发展动力分析
从资产负债表的右侧看企业发展的动力。既表明了资产的权益归属，更表明了企业发展主要的支撑力量。企业在债务类型中的两大支撑力量：
经营性负债（经营）
- 应付票据
- 应付账款
- 预收账款
- 应付职工薪酬
- 应交税费

金融性负债（融资）：是企业具有利息因素的负债
- 短期借款
- 一年内到期的非流动负债
- 交易性金融负债
- 应付短期债券
- 长期借款

企业在股东权益类型中的两大支撑力量：
股东入资：
- 股本（实收资本）
- 资本公积

利润积累：

#### 固定资产与无形资产
企业以存货或业务为核心进行上下游关系管理，而这种管理方式与企业的经营模式和资源采购特征密切相关。除了流动性资产外，企业的经营资产还包括固定资产和无形资产，这些资源共同决定了企业在上下游管理中的能力和效率。固定资产：达到一定的标准以上，企业可以长期利用的有形资源特点：使用单价高，使用周期长关注固定资产在企业的经营中起到什么作用。无形资产（外部购入）：软件，土地使用权无形资产（企业内部产生）：开发支出企业报表对无形资产的反映是不全面的![[img_071.png]]

固定资产（净值）增加约11亿固定资产的原值增加大于11亿（考虑折旧因素）
**固定资产的周转速度**
关注固定资产对企业的经营贡献的时候，我们首先应该关注的是固定资产的周转率或者周转速度。固定资产的周转率或周转速度 = 营业收入 / 平均固定资产原值固定资产净额一直在增加 》原值增加更快如果营业收入增加不多 》 固定资产周转速度在下降固定资产对经营活动的贡献：
固定资产的增长（应该）带来营业收入的增长。
**固定资产的物理利用率**
固定资产的系统管理能力不高固定资产的结构设计与业务不匹配
**无形资产的分析困难**
无形资产与有形资产难以进行对应性的分析对固定资产可分析周转速度对无形资产很难分析周转速度
**经营资产的综合竞争能力**
上下游关系的管理（现金流量的管理）固定资产推动营业收入的能力对固定资产的有效利用经营资产的系统优化：无结构失衡，分析企业经营资产运营效果方面的表现
**经营资产综合竞争力的财务指标表现**
1. 毛利率 = （营业收入 - 营业成本） / 营业收入
2. 销售费用率 = 销售费用 / 营业收入， 竞争力强的企业销售费用率低
3. 管理费用率 = 管理费用 / 营业收入， 如果管理不能推动市场能力，管理是无效的
4. 核心利润率 = 核心利润 / 营业收入 （核心利润 = 营业收入 - 营业成本 - 营业税进及附加 - 销售费用 - 管理费用 - 财务费用）
5. 核心利润产生现金流的能力 = 核心利润 / 经营活动现金流净额， 企业的核心利润产生经营活动现金流量净额
6. 经营资产报酬率 = 核心利润 / 平均经营资产

核心利润高，经营资产报酬率地，如何评价？
--> 市场能力强，经营资产结构失衡（存在不良资产）

政府补贴收入（利用政策牟利）非流动资产的处置收入（公司在迅速萎缩或在战略转型）如果一个企业在合并报表里面大量的靠营业外收入和投资收益来支撑他的净利润的话，这个企业的核心竞争力应该是很不突出的。

### 现金流量表分析
#### 现金流量表的产生背景
- 资产负债表反映企业的资源状况。
- 利润表反映企业的经营效益。两者均采用权责发生制（应计制），因此：
- 营业收入增加不等于货币资金增加；
- 费用或成本增加不意味着货币资金减少；
- 净利润增加不意味着净现金流入增加。在没有现金流量表之前，企业可能出现有利润却缺乏现金流的情况。利润的增加往往带来的是应收账款增加, 存货增加或其他资产占用，并不能直接增强企业的资金周转能力和活力。

现金流量表清晰地表达了企业的各类活动的结构和相互关系，代表了企业的一定时期经营活动，筹资活动，投资活动现金流量的一种结构变化，以及他们的一种相互关系。

#### 经营活动的现金流量分析
看现金流量的净额
**经营活动的现金流量充足性分析**
如果一个企业的存货周转大于2次，企业经营活动的现金流量应为核心利润的1.2 - 1.5倍。企业的核心利润，是投资活动现金流出量的战略支撑；而经营活动的现金流量，才是企业的核心。
**企业有利润，没有现金流量的原因**：
应收票据与应收账款之和的增加存货增加![[img_081.png]]

经营活动产生的现金流量净额是负的。营业利润16.93亿。营业核心利润18亿左右，乘以1.5，至少需要20亿左右的现金流量。为什么反而是负的呢？

应收票据应收账款和存货剧增（积压），所以现金没有了。
![[img_082.png]]

经营活动产生现金流量的能力不强。经营活动现金流量不足以支持他的投资活动。
![[img_083.png]]

营业利润160亿左右，核心利润在170亿左右。存货周转超过两次。现金流量需要200亿左右。实际为189亿，还是有一点不足。为什么呢？应收票据增加的太多了。总结，经营活动产生的现金流量还可以改善。
![[img_084.png]]

（更正：“资产总计”应为“经营活动产生的现金流量净额”，“营业总收入”应为“投资活动现金流出u”）格力电器的投资活动流出量远远小于现金流量净额。说明格力电器不依靠融资，靠经营活动的现金流量就可以进行扩张。
**当企业的经营活动的现金流入量净额不能对其扩张形成战略支撑时，企业的扩张靠什么？**
现有的货币资金存量（筹资所得）筹资活动的现金流入量

#### 投资活动的现金流量分析
看现金流出量的战略含义
**投资活动的现金流量包括**
构建固定资产，无形资产和其他长期资产支付的现金。（企业的扩张主要集中在内部，以强化企业的经营为核心）![[img_085.png]]

特变电工以对外投资扩张为主，内部强化经营能力为辅。

#### 筹资活动的现金流量分析
看现金流入量
**筹资活动的现金流入量包括：**
- 吸收投资收到的现金
- 借款收到的现金
- 发行债券收到的现金

![[img_086.png]]

特变电工的融资能力强，其融资在支撑企业的扩张。效益一直处于波动中。依靠筹资活动支撑扩张（原因在于经营活动的现金流量不足）平均资产的增长速度快于营业收入的增长速度总资产周转速度偏慢，导致综合效率降低。

### 三张报表的综合分析
**三张报表之间的关系**
利润表是对股东权益中利润的形成过程的展开说明现金流量表是对货币资产年度内的变化的结构性展示。现金流量表和利润表是时期报表
**比率分析的各种比率**
- 资产负债表
- 流动比率 = 流动资产/流动负债
- 速动比率 = （流动资产-存货）/流动负债
- 资产负债率 = 总负债/总资产
- 利润表
- 毛利率
- 销售费用率
- 管理费用率
- 核心利润率
- 资产负债表 + 利润表
- 总资产周转率 = 营业收入/平均资产总额
- 经营资产周转率 = 营业收入/平均经营资产
- 固定资产原值周转率
- 存货周转换率 = 营业成本/平均存货原值
- 流动资产周转率 = 营业收入/平均流动资产
- 总资产报酬率 = 息税前利润/平均资产总额
- 净资产收益率（净资产报酬率）= 净利润/平均股东权益余额
- 以核心利润为关键的指标
- 核心利润产生现金流量的能力 = 经营活动现金流量/核心利润
- 经营资产报酬率 = 核心利润/平均经营资产

**比率分析的应用**
比率分析时要区分母公司报表和合并报表。母公司报表反映的是母公司自身的经营状况，而合并报表代表的是整个集团的经营结果。在分析综合盈利能力时，应使用合并报表的数据，因为利润是集团整体创造的。但在分析周转效率时，不宜采用合并报表，因为合并口径中包含大量内部交易，会影响指标的真实表现。大部分比率分析适用于经营性主导的企业，一些比率分析对投资性主导或并重型企业不适用（如资产周转率）。

### 企业风险分析
#### 与风险有关的比率
**与风险分析有关的比率**
- 流动比率 = 流动资产/流动负债
- 资产负债率 = 总负债/总资产
- 利息保障倍数 = 息税前利润/利息支出 （高一些为好，说明支付利息后还有利润）

**与经营风险有关的比率分析**
经营风险：企业的经营资产持续产生盈利能力的不确定性因素
- 毛利润
- 销售费用率
- 管理费用率
- 核心利润产生现金流量的能力
- 经营资产报酬率
- 存货周转率
- 固定资产原值周转率
- 流动比率

**与财务风险有关的比率分析**
与财务风险相关的比率分析主要关注企业获取金融性资金时的不确定性。核心思路是：企业使用贷款是否真的带来足够的收益。常用指标是
- 金融性负债率 = 金融性负债 / 总资产

当一家企业高度依赖贷款扩张时，这个比率往往较高，也意味着其财务风险更大。

#### 与风险有关的其他分析
1. 行业分析
2. 政策环境分析（特定时期的政策对某地行业的生存和发展有相当的影响）
3. 竞争环境分析
4. 以财务信息为依据的分析
- 股权结构，公司治理与核心人物变更
- 贷款集权与分权管理失控的风险

![[img_087.png]]

融资都发生在子公司。中国联通在贷款资金的管理方式上采用的是分权管理。
![[img_088.png]]

其他应收款在母公司与子公司之间相差 27.7 亿元，说明母公司在向子公司提供资金，形成了集团内部资金输送的通道。结合短期借款可以发现，母公司对外贷款后再把资金下拨给子公司，体现出特变电工在贷款层面具有一定的集权化管理特征，有助于降低集团整体融资成本。但从长期借款情况来看，集团同时存在分权化融资路径，整体呈现“分权为主, 集权为辅”的资金管理模式。这种模式虽然灵活，但也容易导致贷款管理失控。将集团整体贷款规模 150 亿元与货币资金 111 亿元对比，可以看到资金链存在“挤高”迹象，资金压力较大。
![[img_089.png]]

与固定资产建设有关的财务费用在决算竣工以前计入相关固定资产的成本。
**财务报表中的“三高”的情况**
贷款总规模高财务费用高不良资产规模可能高
**优质资产**
符合企业战略发展方向并产生相应效益的资产是高质量资产
**不良资产**
闲置的货币资金或长期沉淀下来不予使用且导致企业财务费用增加的资金长期居高不下的在建工程闲置的，利用率不高的固定资产（固定资产增长，但不能推动营业收入增长）
1. 并购不当产生的风险
- 过高的商誉
- 被并购企业与原企业的战略协同效应
- 跨国并购风险（对国外的经营，法规和人文环境不了解）

**惯性依赖的表现和风险**
- 对供应商资金的占用

企业的较低流动资产对较高流动负债的关系。凡是较低流动资产对较高流动负债提供保障的，一定是企业的“两头吃”能力比较强。其表现为应付票据，应付账款和预收款项。

#### 报表里的几个核心项目
**资产负债表的核心项目：**
存货与固定资产 -- 资源与能力
**利润表的核心项目：**
营业收入与核心利润 -- 市场与效益
**现金流量表的核心项目：**
经营活动现金流量净额 -- 利润的质量
**“三个脱节”的风险**
- 存货，固定资产和营业收入的脱节 -- 资源，能力和市场的脱节

投资决策失误经营策略的选择问题用人失当问题
- 营业收入与核心利润的脱节  -- 市场与效益的脱节
- 核心利润与经营活动现金流量的脱节 -- 有利润没钱

#### 从经营资产看企业的前景
![[img_092.png]]
- 固定资产略有增加
- 存货下降
- 营业收入高
- 周转速度加快
- 盈利能力提高
- 经营活动现金提高
- 流动资产和流动负债的对应关系
- 空调市场的天花板

经营与投资并并重型企业![[img_093.png]]

固定资产增加不多。存货增加了。毛利率在下降。总体感觉，特变电工的现金能力下降，利润质量在下降。对特变电工未来的建议：
- 提高新增固定资产的利用率
- 调整产品的生产结构
- 改变产品的销售结构
- 提高产品的毛利率
- 增加销售费用和管理费用的有效性
- 强化上下游关系管理
- 核心是市场竞争能力的进一步提高
#### 从控制性投资看企业前景
控制性投资体现企业对子公司的管理成效
- 控制性投资占用的资源
- 控制性投资撬动的增量资源
- 控制性投资产生的效益

![[img_094.png]]

对营业收入的贡献：2014年母公司1203亿，合并报表1400亿。母子公司是子公司形成了相当多的对母公司的配套。对利润的贡献：母公司利润81.96, 合并报表160亿。利润增加了80亿。子公司对整个集团利润贡献相当大，子公司效益相当的好。对格力电器未来发展的建议：
- 母公司更多地开拓市场
- 子公司对外投资增加新的盈利点或者业务点

特变电工现状：集团分散化融资，子公司大量的固定资产建设，子公司相当规模的营业额，集团的利润和现金流情况不理想。对特变电工未来发展的建议：
- 强化对新增固定资产的产能利用和市场开拓
#### 从融资，重组，并购看前景
取决于债权人和大股东的意愿及其下上结果产能利用和市场开拓。
